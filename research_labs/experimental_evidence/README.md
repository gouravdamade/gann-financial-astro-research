# XE1 Experimental Evidence Lab

This directory holds the immutable, non-market fixture and initial trial-ledger
records for `PFR-V2B-R7-XE1`.

It is deliberately separate from source doctrine, Fields, Auto Suggest, ML,
live inference, MT5, and execution. The fixture demonstrates role binding,
causal grouping, bounded modifier ablation, and an unsigned trial governance
record. It contains no price input or market outcome.

`APRIL_2025_REVIEW_WINDOW` is permanently labelled `TOUCHED_DEV`; it is not a
pristine holdout and is not evaluated by this milestone. The initial Touched
development selector intentionally remains empty until separately admitted
observations exist; it never relabels the synthetic fixture as market evidence.
