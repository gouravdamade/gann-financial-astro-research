# Swiss Ephemeris Distribution Gate

Swiss Ephemeris is offered under a dual-license model: AGPL or a professional
license. The project currently uses it locally for private research. This file
does not offer legal advice.

Before distributing a Windows build that contains or depends on Swiss
Ephemeris, the project owner must select and document a compatible license path
and review the obligations for the Python and Rust/Tauri packaging design.

Official reference:

https://www.astro.com/swisseph/swephprg.htm

Release status: blocked for SBC distribution until resolved.
