# Phase 3A Acceptance Gates

Phase 3A is accepted only when all of the following pass:

1. Rashi-correction gate: the six corrected top/bottom rashi cells match both
   held figures and leave `(3,3)` and `(7,3)` vacant at the rashi layer.
2. Worked-example gate: Krittika, Rohini, and Mrigashira each derive the exact
   nine printed targets from the board.
3. Full-ring geometry gate: all 28 source nakshatras produce two side rays and
   one opposite/front target with a nine-target union.
4. Motion gate: fixed bodies use the selected profile; the five variable-speed
   planets require an explicit motion class.
5. Nature gate: conditional Moon/Mercury states remain unresolved unless
   caller context is supplied.
6. Multiplier gate: source multipliers are exact; unresolved stacking or
   precedence is not guessed.
7. Transparency gate: every scored match exposes actor, direction, target,
   nature, multiplier, signed units, status, and explanation.
8. Normalization gate: favorable, adverse, net, normalized balance, and
   coverage remain separately visible.
9. Citation gate: both the profile and every target resolve held-page evidence.
10. Isolation gate: no market-direction word, price signal, trade field,
    Auto Suggest, broker instruction, or MT5 execution appears.
11. Regression gate: all prior SBC and repository tests pass.

Passing these gates certifies a read-only research-guidance backend. It does not
certify predictive or financial value.
