# Phase 1 Acceptance Gates

Phase 1 is accepted only when all of the following pass:

1. Source gate: profile source IDs resolve and interpretive features remain
   false.
2. Astronomy gate: aware UTC input, Raman/Lahiri separation, true/mean node
   selection, Ketu derivation, speed, returned flags, fallback mode, and data
   evidence are tested.
3. Panchanga gate: nakshatra and pada boundaries, tithi, karana, yoga, civil
   Vara, and sunrise Vara boundaries are tested.
4. Reproducibility gate: identical requests produce identical snapshot IDs;
   machine-specific paths do not define identity.
5. Isolation gate: the package imports no decision engine, market data, Auto
   Suggest, MT5 execution, or chart UI modules.

Passing these gates certifies only the deterministic foundation. It does not
certify any Sarvatobhadra interpretation or financial usefulness.
