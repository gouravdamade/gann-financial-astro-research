# Trailokya Dipika 1972 Translation Continuation Plan

This plan is a source-closure map, not authorization for implementation.

1. **Motion-state contract:** transcribe any source definition of swift, mean,
   stationary, and direct-slow states. If no definition closes, preserve
   explicit caller-supplied states only.
2. **Target geometry:** certify a Trailokya-specific cell mapping and the
   corner/junction treatment. Do not borrow the Phaladeepika shared fixture.
3. **Moon and Mercury conditions:** convert only expressly defined source
   conditions into a separately reviewable, timestamp-safe contract.
4. **Modifier precedence:** locate source text for coexistence of retrograde,
   exaltation, debilitation, and swift conditions. Without it, retain isolated
   labels rather than a scalar.
5. **Latta:** audit it as a distinct source module. Its presence in the source
   is not an executable operator.
6. **Arghya:** seek an independently reproducible worked calculation that
   states all input selection, subtotals, conversion and final result before
   considering any further research use.

Every step must maintain source-profile isolation, preserve unknowns, and
avoid market mapping until a separately authorized validation path exists.
