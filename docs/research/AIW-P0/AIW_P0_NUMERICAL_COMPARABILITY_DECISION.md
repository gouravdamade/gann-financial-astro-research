# What can be compared

| Level | Decision | Reason |
|---|---|---|
| 1. Equal native unit | Accept | One favorable mark means one eligible natal reference satisfying a listed relative place for the selected recipient. Eight references are inspected in each chart. |
| 2. Same planet across two charts | Accept as a descriptive count | Within the same edition, stage, epoch and zodiac, count differences use the same mask. In Sun/Gemini the two charts yield 5 and 2, giving +3 marks. In Mars/Cancer both yield 4. |
| 3. Cross-planet aggregation | Withhold as a total influence score | Same-size integers have different recipient rules and annual sign totals. Sun totals 48, Mars 39. Equal weighting across each planet’s current transit sign needs a separate operator. |
| 4. Realized-result comparison | Withhold | Equal counts can involve different qualifying houses, dignity, strength at delivery and neutral-place conventions. There is no accepted chart-to-chart interval scale for realized phala. |
| 5. Applying natal methods to currencies | Experimental | The epochs are accepted founder hypotheses for calculation. Classical human natal testimony does not establish the interpretation of those marks for currencies. |
| 6. Financial prediction | Unestablished | No market evidence was used or sought. A positive mark difference solely records which reference chart supplied more favorable conditions for this planet. |

**One legitimate different sum.** Sastri’s *Bṛhat Jātaka* plate notes, pp211–213 (scan approximately pp246–248), describe a Samudāya count formed by adding favorable entries for the **same sign** across grahas. The plate uses Aries 34 in its own illustrative chart. If we apply the seven 1905 masks to Aries in the *different* p100 Mars horoscope, the component counts are 4,1,3,5,5,4,2, totaling 24. This is a reconstruction of a named same-sign tally. It does not authorize adding Sun-in-Taurus to Mars-in-Cancer and calling the result chart-wide realized influence. Results from tables with different reduction stages should also have different identifiers. [Sastri edition](https://astrojyotish.info/literature/brihat-jataka-sastri/)

**Conditions for the admitted comparison.** Record edition, mark convention, recipient, signs, contributor vector, fixed chart identities and epoch. Pair only like values. Missing or boundary-ambiguous input propagates unknown or a set of possible counts. A signed difference may be zero while its proof differs. A cross-edition difference caused by the neutral Mars place is a disagreement about measurement and needs its own record.
