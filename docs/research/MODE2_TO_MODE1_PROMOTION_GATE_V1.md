# Mode 2 to Mode 1 Promotion Gate V1

This is an executable checklist for one variable and one named source profile.
Passing a backtest, visual fit, calculator comparison, or LLM explanation is
never a substitute for any unchecked item.

## Required lifecycle

`MODE2_EXPERIMENTAL` -> `SOURCE_CANDIDATE_IDENTIFIED` ->
`SOURCE_PACKET_COMPLETE` -> `DEPENDENCIES_RESOLVED` ->
`IMPLEMENTATION_VERIFIED` -> `INDEPENDENT_CHECK_PASSED` ->
`FOUNDER_REVIEW_PENDING` -> `APPROVED_FOR_SOURCE_ONLY`.

Exit states: `SOURCE_MISSING`, `CONFLICTED`, `VERIFICATION_FAILED`,
`DEPENDENCY_BLOCKED`, `REJECTED`, or `REMAIN_MODE2`.

## Required checks

- [ ] Define one role only: polarity, magnitude, activation, timing,
  protection, obstruction, conflict, capacity, coverage, or display.
- [ ] Record identified edition, source profile, language, exact page/verse/table,
  checksum, content layer and immutable packet hash.
- [ ] Show that the source supports the actual category, value, formula,
  threshold, order, or stack rule being implemented.
- [ ] Close every dependency: chart identity, time accuracy, location/house
  policy, ayanamsha, ephemeris, motion state, dignity, target identity and
  selected source profile.
- [ ] Specify `SOURCE_MISSING`, `UNKNOWN`, `CONFLICTED`, `NOT_APPLICABLE` and
  dependency-blocked behavior as null/gap, never substitution.
- [ ] Preserve conflicting profiles separately; do not average doctrines.
- [ ] Document stacking/precedence; when silent, return separate components and
  unknown combined magnitude.
- [ ] Reproduce the output from identical chart/time/profile/code inputs.
- [ ] Add page-derived worked fixtures and an independent implementation,
  calculator or edition where required.
- [ ] Test edges: stations, sign/dignity boundaries, sunrise/local-time changes,
  missing times, duplicate rows and conflict paths.
- [ ] Complete a double-counting review across SBC, aspects, strength, Panchanga
  and Ashtakavarga.
- [ ] Confirm no market outcome, return, correlation or visual fit selected the
  rule or parameter.
- [ ] Obtain a founder decision for this immutable version: `APPROVED_FOR_SOURCE_ONLY`,
  `APPROVED_WITH_LIMITS`, `MORE_EVIDENCE_REQUIRED`, `CONFLICTED`, or `REJECTED`.
- [ ] Verify mode isolation: Mode 1 excludes Mode 2 values, Mode 3 has no score,
  exports replay, and execution/Auto Suggest/order locks remain false.
