# Source, domain and limits of each decision rule

Locators follow the named copies. Printed page first, one-based file ordinal second. “Worked” identifies whether the author actually applies the particular rule in a case. A Sanskrit work, an English translation, a translator’s note and a modern computation have distinct authority.
