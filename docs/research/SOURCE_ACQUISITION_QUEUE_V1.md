# Source Acquisition Queue V1

Status: R4 planning only. Do not download copyrighted material automatically.
Every accepted item needs an identifiable edition, checksum, page images,
content-layer classification, exact locator, and human review packet.

## Deferred Muhurta candidates

Create acquisition records for *Muhurta Chintamani*, *Kalaprakashika*, and
*Dharmasindhu* only after a specific edition is found. No web summary may be
turned into an executable Vara, Rahu Kala, Yamaganda, Gulika, Tara Bala, Chandra
Bala, or combined Muhurta rule.

## Acceptance packet for any source

1. Title, author/tradition, translator, publisher, edition, language and content layer.
2. Legal local copy/reference, file checksum and page-image range.
3. Verbatim locator plus a human-reviewed translation/extraction.
4. Variable IDs affected, exact numerical/ordering support, and dependency limits.
5. At least one source-derived fixture; independent witness where the coverage
   matrix marks it necessary.
6. Founder decision for the exact packet version. No packet alone alters a mode.
