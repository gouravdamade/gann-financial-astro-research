# Model C · A constrained quantitative projection

**Research purpose.** Ask what numerical conclusions would follow *if* a defined field could be projected into a common measure. Return the set of values consistent with the assumptions. For an unbounded or untyped missing term report an unidentified result. A narrow interval is informative only if its constraints are defensible.

For one subject, unit u, target domain d and source profile p, form a vector x(t) of distinct, eligible primitives. Its entries can be binary activities or sourced measures converted into u by a declared map. Define the admissible parameter set Θ. A possible side value is

    z(c,t;θ) = Σᵢ wᵢ xᵢ(c,t) + Σₑ βₑ gₑ(c,t)
    I(c,t) = {z(c,t;θ) | θ∈Θ and all required inputs are covered}.

Each gₑ represents a specifically identified interaction. Exclude interactions already represented as modifications of x. An unsupported potential interaction does not earn a coefficient. If it is required for the requested *total*, withhold that total. Use a separate restricted projection if its universe can be enumerated. “Coefficient fixed at zero” is itself a substantive exclusion when used as a model of all effects.

## Three quantitative hypotheses and their prices

| Model restriction | Result and unit | Assumption requiring evidence |
|---|---|---|
| Every eligible event has w=+1 or −1 and binary activity | Signed count of unique active records | Equal votes, disjoint counting units, eligible direction for each, frozen event universe |
| A source gives m, an explicit sign and a time law k | w·m·k has meaning only under stated units | m measures this result, not general ability. Any source-defined ordinal score needs an interval-scale justification before taking differences |
| A base effect is multiplied by an isolated modifier | Modified result in its original unit | Same base, target, factor and guard as the rule. Combining several multipliers requires a separate stacking law |

A free smooth k, cross-domain sum, min/max as strongest-wins, fixed weights or confidence discount are Mode 2 assumptions. Uncertainty about a translation is epistemic. Reducing its weight by 50% invents half an effect. Branch on the readings instead. A non-additive capacity (e.g. a Choquet integral) could encode cooperative subsets if their ordered capacities can be elicited and independently justified. Without them there are exponentially many unidentified subset values. B has fewer ungrounded degrees of freedom.

## Identification and sensitivity

For finite scenarios compute the attainable set directly. For linear z and a bounded polytope Θ, solve two linear programs for min and max. Bounds can enclose unattained interior values in discrete scenarios; retain the feasible scenarios. In a synthetic example with favorable activity and adverse activity both present and weights u∈[1,2], v∈[1,3], z=u−v∈[−2,1]. Both signs are consistent. With the extra assumption u=v the same records give zero. The equality constraint changes the conclusion without any astronomical change. If only ordinal “weak/strong” is known, a monotone recoding can change a sum or even its ordering. Retain only invariant comparisons.

For USD/JPY use shared θ for shared rule uncertainties. Compute min/max of z(USD;θ)−z(JPY;θ) jointly. If identical features have the same positive unknown weight, the difference can be exactly zero even while each separate interval is broad. Independent endpoint subtraction then yields only a conservative enclosure. Different missing chart-specific predicates can widen the set again.

## Computation and possible implementation

Begin with a frozen graph output having one compatible native measure and one record per distinct consequence. With k active terms and S enumerated joint interpretations, evaluating a linear projection costs O(kS) at each distinct change time. When coefficients lie in a polytope, the two extrema require separate optimizations whose costs depend on dimension, constraints and solver precision. Discrete guard choices can make the scenario set exponential. Record the assumptions attaining each bound. If certified weights or missing-term bounds are absent, restrict output to a declared engineering count or return unidentified. Render the set or bounds at the canonical times; averaging endpoints over a week need not give attainable weekly bounds under shared parameters. Optimize the window functional jointly if that is the requested observable.

## Source audit and outcome

Vyas vv161–166 supply a concrete counterexample to generic strength weighting. Own-sign strength is high for both classes, while their positional-result ordering differs. In its Vedha setting the Hindi exposition gives own/friend/neutral/enemy positional results 20/15/10/5 for the benefic and 5/10/15/20 for the malefic. Those numbers may be copied into their own native table under an approved profile. Applying them to Mercury's gocara benefit, standardizing them to a 0–1 “currency force,” or making 20 twice as financially favorable as 10 would require new hypotheses. The long-term candidate is a graph with such quantitative projections wherever calibrated internal units, joint conditions and temporal support exist. No general side magnitude is identified today.
