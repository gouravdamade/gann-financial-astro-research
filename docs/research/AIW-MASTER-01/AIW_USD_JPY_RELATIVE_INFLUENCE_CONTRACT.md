# Contract for USD minus JPY

The intended result is W(t)=I_USD(t)−I_JPY(t). It is a partial operation with a declared output unit. The always-available fallback, when side evidence exists, is the ordered pair of labelled side records. A missing value on one side is visible. A negative difference, if ever admitted, means less of the specific measured quantity on USD. A price-direction interpretation would be another hypothesis.

## Inputs and comparison conditions

| Question | Decision |
|---|---|
| Same doctrine? | Use the same edition, operator, target semantics and profile for direct projection. Different profiles require a justified, versioned equivalence map tested on the same inputs. Similar labels do not establish equivalence |
| What units? | The same interval or ratio scale oriented in the same direction, known origin convention and common scaling. On a purely ordinal scale one may compare levels within the same ordered domain but differences have no invariant size |
| What normalization? | Identity by default. An explicit common affine rescaling changes scale predictably; side-specific z-scores or rescaling to each side's maximum change the estimand. A proportion of eligible records is a different measure with its own denominator |
| What is comparable before subtraction? | Source-matched components and ordered categories. A favorable family result cannot be offset against harm to reputation by assigning both one point |
| What about unequal event counts? | Define the opportunity universe in advance, match duties of transit and target, deduplicate repeated citations. Report numerator and denominator for each side. A larger corpus, finer event splitting or longer exposure can manufacture dominance |
| How to handle missingness? | Unknown stays unknown for the affected requested quantity. Mixed preserves both components. If justified bounds exist on every unknown, produce an identified set. A resolved side and an unidentified side yield a partial pair |
| Local interactions? | Evaluate them on their own chart, with their own effective guards. Only compare the resulting homologous measure; never cancel a USD modifier directly against a JPY baseline |
| Shared uncertainty? | Evaluate both sides under the same admissible interpretation when they share an uncertain rule. If all scenarios order USD above JPY, report a robust ordinal result in that domain. If they disagree, display the alternatives |
| Is a universal scalar necessary? | No. A vector of paired components, a 2D side state, a partial order or a matched engineering occupancy difference can all be defined earlier |
| Are chart hypotheses price hypotheses? | No. The chart identity and currency analogy must be frozen first. A subsequent mapping from category to financial pressure, even for the same currency, needs its own registration |

## Output decision procedure

1. Preserve identity, UTC, subject analogy, birth-Moon reference, target universe, measure ID, interval, guard coverage, units and rule-set hash independently on each side.
2. On matching categorical records output (state_U,state_J), with proof IDs. Where the same named dimension has a documented order, output its ordering. A product partial order can leave vectors incomparable if USD exceeds JPY on one coordinate but falls below it on another.
3. If a common numerical quantity is fully identified compute its difference. An engineering example is the percentage-point difference in the share of a fixed UTC window spent in the same matched base category. The result measures time, not good fortune.
4. For interval-valued marginals [Lᵤ,Uᵤ], [Lⱼ,Uⱼ], enclosure is [Lᵤ−Uⱼ,Uᵤ−Lⱼ]. For shared constraints calculate the exact joint range if possible. If no bounds are supportable, return UNIDENTIFIED. Do not interpret ±∞ as a measured value.
5. Produce separate statuses for source scope, completeness, mathematical comparability and financial validation. A comparable pair of counts can still have no defensible market meaning.
