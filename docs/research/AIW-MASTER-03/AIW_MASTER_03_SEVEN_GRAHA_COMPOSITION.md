# What exactly is being added?

Let H[p,c,z] be the count of favorable marks in recipient p's unreduced table for sign z. For each of eight contributors q, compute r=1+((z-z_q) mod 12), then test membership in the edition-specific mask M[p,q]. B[p,c,t]=H[p,c,z_p(t)]. Two contributors in the same sign remain different references; their rule tables can differ. Identity is recipient, contributor, chart, sign, source profile and reduction stage, not longitude alone.

For a fixed chart, the twelve H values sum to 48,49,39,54,56,52,39 respectively. This follows by translating each mask around the circle, not by observing transits. The uniform-sign baseline per recipient is therefore 4, 49/12, 3.25, 4.5, 14/3, 13/3, 3.25. Time-occupancy averages need not equal these means. Subtracting each uniform-sign mean leaves the same two-chart contrast when both sides use identical masks. It does change the zero of each side curve. Dividing by eight expresses a fraction of references, not a probability.

The simultaneous diagonal sum has units “favorable recipient/contributor entries” (0..56), not seven independent votes, virupas or phala. Zero means no favorable entries; 28 is half of 56, not doctrinal neutrality. Equal weighting and uniform-sign centering are engineering choices. Do not import the Phaladipika same-sign threshold onto the diagonal.

A source-sensitive alternative stores (F,A,N). F+A+N=8 when fully known. Signed raw excess E=(F-A)/8=(2F+N-8)/8. Neutral classification is known evidence, unlike a missing mark. In the edition variant, the Mars/Moon tenth place changes adverse to neutral: one worked cell changes (3,5,0) to (3,4,1); F stays 3 while E changes from -0.25 to -0.125. Never merge masks across witnesses to “fix” discrepancies.

Unknown weights give a non-additive output **set** even though each candidate projection is linear. Use the same probability simplex on both charts: range of weighted pair difference equals [min d_p,max d_p]. A partial order survives if all d_p share a weak sign; strict everywhere requires all strictly that sign. See MATHEMATICAL_MODELS for categorical rule arbitration and multidimensional alternatives.
