# What “continuous in time” can mean

Being queryable at any supported instant does not mean a function is smooth. On the domain of the retained ephemeris replay, B is piecewise constant. The primitive support for a sign is [ingress,egress); in this fixture each detected ingress lies **between adjacent whole seconds**. Treat the bracket as uncertain, not an exact subsecond event. Agreement across multiple scan steps is evidence, not proof no brief re-entry was missed. At a boundary update all affected subjects together. A step held within an established sign is not forward-filling an unknown observation.

1. S(t) samples one specified sign; E(t) uses union of seven sign transitions. Both can be evaluated off the display grid. A coarser view must preserve or count changes; an empty pixel is not a zero mark.
2. W(t)=sum k_p(t)B_p(t)/sum k_p(t). Within fixed sign bins derivatives come from the explicit strength calculation, never connecting state samples by a spline. Dignity/house transitions can create additional jumps. Negative or missing required k invalidates W.
3. H(t) is an event-driven rule state. Recompute only affected predicates at occupation changes, exact instants or domain-specific activation/expiry. Named period and subperiod can nest; conflicting rules do not establish persistence or force. A sampled fact without transition evidence is a point.
4. R1(t)E(t) varies within steps only because actual geometry changed. Kinks near zero coherence; do not manufacture a preferred direction where the mean vector vanishes. This hybrid is not a classical waveform.
5. V(t) stores fast lunar events, slow planetary states, local sunrise/day rulers, and independent geometry/strength coordinates. Different scales coexist; no assumed “higher wave overrides lower wave”. Time averages, integrals (mark-days), wavelet detail or state-space filters would be representations of the observed signal, not new classical evidence. No smoothing or dynamical memory is needed to see nested changes.

Query invariant: given identical UTC, frame, body IDs, fixture, profile and coverage, M1/M5/H1/H4/D1/W1 must return identical values. Existing discrete geometry UI may select a different *sample* at the same crosshair; disclose sample UTC or unavailable and never compare those as identical queries. For coarse charts show real transitions/extrema and their timestamps; do not average into a fabricated instantaneous value. Price candle availability must not change the definition of the astronomical function.
