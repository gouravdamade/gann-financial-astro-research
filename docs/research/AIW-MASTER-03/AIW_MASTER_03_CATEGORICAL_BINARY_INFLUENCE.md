# A financial band is an answer to a named question

Store predicate truth separately from the interpretation. Key by edition, rule, subject, chart, financial question, time basis and evidence identities. A subject outside the rule yields NOT_APPLICABLE before inspecting planetary values. Do not evaluate a merchant income rule on the exchange rate.

|Input or result|Display contract|
|---|---|
|All required premises established|CONDITION_PRESENT; show FAVORABLE or UNFAVORABLE only if that consequent is explicit.|
|A necessary premise disproved|CONDITION_ABSENT; no converse judgment.|
|Evidence missing for a decisive premise|UNKNOWN with missing field/coverage reason. An unobserved omen is not a negative observation.|
|Source itself assigns mixed effects|MIXED, split texture, preserve both aspects.|
|Independent contradictory rules, no arbitration|Keep parallel records and an unresolved conflict reference, not a synthesized MIXED verdict.|
|Source explicitly assigns neutrality for the question|NEUTRAL, labelled; do not use it for cancellation, no record, or unknown.|
|Different subject or topic|NOT_APPLICABLE, separate from unknown.|

**Boundaries.** Store exact observation or half-open UTC support with original civil/calendar evidence, not both by assumption. Intersect only intervals with established validity. Unknown endpoints produce uncertain boundaries, not a forward-filled segment. Day summaries list the states actually present and coverage; hours and minutes reveal the same transitions. Preserve a simultaneous boundary once per rule identity.

**Design choice.** Prefer separate labelled lanes (D) using intervals with redundant color and texture (A). A binary step (B) can assign visual y=+1/-1 to two explicit opposing judgments for the *same question*; no arithmetic, statistics or cross-rule subtraction on these coordinates. A false buying predicate uses a presence/absence lane, never the adverse rail. A stepped crest/trough (C) adds no information and risks implying size: no curves or interpolation. A composite (E) must identify a controlling passage, operands and exact branch, e.g. BJ VIII.23. Provide the original statements in the inspector.

**Acceptance fixtures (design only).** On BPHS XLII.13: active P + relevant association + complete empty trinal-aspect set = triggered adverse; same with one trinal aspect = absent; same with incomplete empty set = unknown. Moving to a currency quote subject = inapplicable. On annual mixed testimony: retain MIXED through a D1/H1 change. On a documented commodity omen: render the observation as a point and any stipulated disposal date separately; never paint a predicted appreciation across intervening hours.
