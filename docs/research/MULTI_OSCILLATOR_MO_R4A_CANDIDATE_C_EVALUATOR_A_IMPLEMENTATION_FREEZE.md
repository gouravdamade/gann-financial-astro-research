## Component Contract

The implementation derives the eight declared row templates for each frozen
event and emits exactly these ordered fields:

`eventId, sourceProfile, componentId, sourceContractId, inputIdentity, inputIdentityHash, outputStatus, sourceValue, unknownReasonCode, provenance`

`VALUE` rows contain `sourceValue` and no `unknownReasonCode`; `UNKNOWN` rows
contain the declared `unknownReasonCode` and no `sourceValue`. Row keys, field
sets, provenance, input hashes, and the allowed UNKNOWN taxonomy are validated
strictly.

The source-specific component boundaries are:

- C01: Moon/Mercury remains source-unknown; no fallback is supplied.
- C02: directed transit-body to natal-target input; no node or self fallback.
- C03: sign-derived relative place using the frozen source-neutral calculation.
- C04: Saravali natural relationship only, from the Saravali source contract.
- C05: ordinary and special Drsti records remain separate rows.
- C06: only the enumerated source motion table is admitted; no modern speed
  threshold is introduced.
- C07: individual modifier dependency remains `UNKNOWN` and is never composed.

No modifiers are stacked, no unresolved strength is combined, no precedence or
cancellation is inferred, no D_i strength is created, and no wave or score is
produced.
